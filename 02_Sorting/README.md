## 📚 About Sorting

Sorting is the process of arranging elements in a particular order,
usually ascending or descending.

Sorting algorithms are fundamental in DSA because many efficient
searching and problem-solving techniques require sorted data.

## 📊 Algorithm Comparison

| Algorithm | Best | Average | Worst | Space |
|---|---:|---:|---:|---:|
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n)* |

\* Auxiliary space depends on the implementation and recursion depth.
